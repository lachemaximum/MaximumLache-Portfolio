## セール時期

お買い物マラソン、楽天スーパーSALE の期間は、その日の3本のうち1本を「ゲーム周辺機器のまとめ記事」に差し替える。

## 商品の選定基準

`scripts/fetch_products.py` が下の JSON を読む。数値は仮置き（未決事項）なので、決まったら書き換える。

```json product_criteria
{
  "hits": 30,
  "min_review_count": 30,
  "min_review_average": 4.0,
  "per_tier": 3,
  "exclude_days": 14,
  "ng_words": ["中古", "ジャンク", "訳あり", "レンタル"]
}
```

- `per_tier`：価格帯（安い・中間・高い）ごとに残す件数
- `exclude_days`：この日数以内に記事で使った商品は除外する
