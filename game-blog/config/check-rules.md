# 公開前チェックの基準

本投稿にするため、公開前チェックが最後の砦になる。次のどれかに引っかかった記事は投稿せず、理由を `logs/post_log.md` に残す。

| 項目 | 基準 |
|---|---|
| PR表記 | 冒頭（本文の最初の数行）にある |
| 楽天リンク | 1つ以上あり、楽天のリンクはすべてアフィリエイトリンク（`hb.afl.rakuten.co.jp`） |
| 断定表現 | 「勝てる」「必ず」など、効果を断定する言葉がない |
| 価格 | 本文に価格を直書きしていない（「12,980円」「¥3980」など。「1万円台」のような帯はよい） |
| 構成 | 文字数、見出し（`##`）の数が基準内 |
| タイトル | 投稿済みの記事、同じ日の他の記事と重複していない |
| 事実確認 | フロントマターが `fact_check: ok` |

落ちた記事があっても、通過した記事は予定どおり投稿する。

## 数値と語句

`scripts/check_article.py` が下の JSON を読む。文字数と見出し数は仮置き（未決事項）なので、決まったら書き換える。
お試しで見つけた問題は、ここと CLAUDE.md に反映する。

```json check_rules
{
  "pr_markers": ["【PR】", "プロモーションを含みます", "アフィリエイト広告を利用しています"],
  "pr_within_lines": 5,
  "banned_phrases": ["勝てる", "必ず", "絶対に", "確実に", "間違いなく", "100%", "誰でも上手く"],
  "min_chars": 2500,
  "max_chars": 10000,
  "min_h2": 3,
  "max_h2": 10
}
```

- 文字数は、HTML タグ・URL・Markdown 記号を除いた本文で数える
- 断定表現は、否定の文脈（「必ずしも〜ではない」など）でも引っかかる。言い換えて避ける
